- When a technical explanation is confusing, prefers it to be restated in simple, concrete terms with a small before/after code example and a clear description of what should happen; explanations should directly address whether independent request inputs can still interact through shared mutable backend state. Confidence: 0.82
- Wants to keep the specific library/tool they chose working (e.g. ragas) rather than having it swapped out for a custom reimplementation or alternative approach; pushes back ("i wanted to use rags bro i showed you error to fix") when the agent offers workarounds/options instead of fixing the reported error. Confidence: 0.7
- Uses a casual, informal register with the agent — addresses it directly (e.g. "bro") and asks blunt one-line questions like "why impro t not working" — rather than formal phrasing. Confidence: 0.55

Confidence: 0.68
